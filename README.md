# Aprendiendo Git & Github
- Estos son los pasos para iniciar con Git
## Paso 1
- Iniciar el nuevo repositorio
```
git init
```
- Directorio de trabajo donde se escribe el codigo

## Paso 2
- Enviar los nuevos archivos o archivos modificados, al area de preparacion
```
git add index.html
git add .
```
- El area de preparacion es donde se preparan los cambios

## Paso 3
- Registrar una descripcion del cambio realizado
```
git commit -m "proyecto base"
```
